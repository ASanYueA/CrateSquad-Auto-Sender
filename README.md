# CrateSquad Auto Sender

> 战术小队（Squad）自动建队工具  
> 快速、批量地向游戏控制台发送 `CrateSquad a b` 命令

---

## 简介

**CrateSquad Auto Sender** 是一个运行在 Windows 平台的小工具，用于在《战术小队》（Squad）游戏中自动、快速地发送建队命令。  
你只需要输入一次队伍名称和参数值，程序便会拼装好完整的 `CrateSquad` 命令，之后按下 **F1** 即可开始/停止连发，把命令以最快速度送入游戏控制台。

---

## 功能特性

- 输入队伍名称：至少 3 个汉字 / 字母 / 数字，不足 3 个字符自动在末尾补空格
- 输入参数值：仅接受 `0` 或 `1`，其他输入会提示错误并重新输入
- **F1 全局热键**：一键开始 / 停止连发，游戏窗口在前台时也能响应
- 使用 `SendInput + KEYEVENTF_UNICODE` 发送字符，支持中文队名
- 控制台 UTF-8 输出，避免中文乱码
- 连发速度可调，默认每条命令间隔 1ms，兼顾速度与稳定性

---

## 环境要求

- Windows 7 及以上
- Visual Studio 2019 / 2022（推荐）
- 或 MinGW-w64（gcc）

---

## 编译方法

### 使用 Visual Studio

1. 新建一个 C 语言项目，将源码文件（例如 `cratesquad.c`）添加到项目中。
2. **将源文件另存为 UTF-8 带签名**（文件 → 高级保存选项 → 编码选 `Unicode (UTF-8 带签名) - 代码页 65001`）。
3. 确保项目链接了 `user32.lib`（默认已链接）。
4. 按 `Ctrl + F5` 编译运行，或使用开发者命令行：
   ```bash
   cl cratesquad.c user32.lib
